## 结构
- 固定顺序：场景/背景 → 主体 → 关键细节 → 约束 → 输出意图
- 说明用途（广告 / UI 稿 / 信息图），它决定成品精度
- 复杂需求用短标签行，不要写成一整段

## 增补尺度
- 用户提示已经具体详细 → **只整理成清晰规格，不加创作要求**
- 用户提示很泛 → 可以补能实质提升效果的细节
- `sample-prompts.md` 里的范例是**完整配方**，不是"每次都要补这么多"的默认值
- 要照片感就直接写 `photorealistic`，并配上真实质感描述：
  毛孔、皱纹、布料磨损、材质颗粒、日常的不完美细节

## 允许与禁止的增补

允许补：
- 构图与取景提示
- 用途 / 精度提示
- 实用版式指导
- 让需求成立的具体场景细节

禁止补：
- 用户没提的角色、道具、物体
- 品牌配色、口号、故事线
- 毫无布局依据的左右站位

## 构图与版式
- 在确实有帮助时才指定取景和视角（特写 / 全景 / 俯拍）
- 资产明显需要放 UI 或文案时，点明**留白**
- 除非用户或周边版式支持，否则不要擅自决定左右布局
- 涉及人物时，必要时描述取景范围、视线、动作
  （`full body visible`、`looking down at the book`）

## 约束与不变量
- 写明什么不能变（`keep background unchanged`）
- 编辑类一律写成 `change only X; keep Y unchanged`，
  **每次迭代都重复这些不变量**，避免逐轮漂移

## 图中的文字
- 逐字文字放引号里或全大写，并指定字体风格、字号、颜色、位置
- 冷僻词如果要求准确，就逐字母拼出来
- 强调**逐字渲染、不得多出任何字符**
- 小字、密集信息图、多字体排版 → 用 `-q medium` 或 `-q high`

## 输入图与参考图
- 不要默认每张图都是编辑对象
- 按序号 + 角色标注：`Image 1: edit target`、`Image 2: style reference`
- 只作风格/构图参考、且用户没要求修改 → 按 generate 处理
- 合成类要说清图与图之间怎么互动
  （`place the subject from Image 2 into Image 1`）

## 有意识地迭代
- 先用干净的基准 prompt，之后**每次只改一个点**
- 迭代时重新声明关键约束
- 优先做单点微调，不要整段重写

## 透明背景
- 用 `-b transparent` 直接要真透明背景，不要自己抠图再拼

## 按用途的提示要点

Generate：
- `photorealistic-natural` — 写成像真实照片被抓拍那一刻；用摄影语言
  （镜头、光线、取景）；强调真实质感；除非用户要求，否则别过度精修
- `product-mockup` — 描述产品/包装与材质；确保轮廓干净、标签清晰；
  需要图内文字时要求逐字渲染并指定字体
- `ui-mockup` — 先说目标精度（可交付的稿 / 低保真线框），
  再讲版式、层级、实用 UI 元素；避免概念艺术式描述
- `infographic-diagram` — 明确受众与阅读流向；逐个标注部件；
  要求逐字文字；密集标签要用更高 quality
- `scientific-educational` — 明确受众、教学目标、必需标签、
  科学准确性要求、箭头、便于扫读的留白
- `logo-brand` — 简洁可缩放；要强轮廓和均衡留白；
  除非要求，别加装饰
- `ads-marketing` — 写成创意简报：品牌定位、受众、调性、场景、
  必须出现的准确 slogan
- `productivity-visual` — 指明具体产物（幻灯片 / 图表 / 流程图），
  定义画布与层级，给真实标签和数据，要求排版可读、间距精致
- `illustration-story` — 定义分镜或情节节点；每个动作要具体
- `stylized-concept` — 指定风格线索、材质表现、渲染方式
  （3D / 厚涂 / 黏土），不要凭空加故事元素
- `historical-scene` — 交代地点与年代，要求时代准确；
  服饰、道具、环境都要符合那个时期

Edit：
- `text-localization` — 只改文字；保持版式、字体、间距、层级；
  不加词、不重排
- `identity-preserve` — 锁死身份（脸、体型、姿势、发型、表情）；
  只改指定部分；光线阴影要匹配
- `precise-object-edit` — 说清要移除/替换什么；保留周围质感与光线；
  其余不动
- `lighting-weather` — 只改环境条件（光影、氛围、降水）；
  几何、取景、主体身份不动
- `background-extraction` — `-b transparent` 求干净抠图；
  保住细节边缘和标签文字；不要光晕、不要顺带改风格
- `style-transfer` — 指明要保留的风格线索（配色、肌理、笔触）
  和必须改变的部分；加 `no extra elements` 防止漂移
- `compositing` — 按序号引用输入图；说清谁移到哪；
  匹配光线、透视、比例；保持底图取景不变
- `sketch-to-render` — 保持布局、比例、透视；
  选能支撑草图的材质与光线；不加新元素
